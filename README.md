<section id="About SHI X">
  <h1>About SHI X</h1>
  <p>ยินดีต้อนรับสู่ <strong>SHI X</strong> — เราคือแพลตฟอร์มด้านข้อมูลและเทคโนโลยีของสถาบันวิจัยสังคมและสุขภาพ ที่รวบรวมข้อมูลของชุมชน งานวิจัยและข้อมูลที่เกี่ยวข้องกับสถาบันวิจัยสังคมและสุขภาพ </p>

---
</div>
<section id="About CHL">
  <h1>About CHL</h1>
  <p>ยินดีต้อนรับสู่ <strong>CHL</strong>  
    "CHL" หรือ Community Health Link เป็นระบบข้อมูลสุขภาพชุมชนที่ถูกพัฒนาขึ้นเพื่อเชื่อมโยงข้อมูลสุขภาพระหว่างชุมชนกับหน่วยงานท้องถิ่นและภาครัฐ จุดประสงค์คือเพื่อให้การดูแลสุขภาพระดับชุมชนเป็นเรื่องใกล้ตัวและเข้าถึงง่าย ระบบนี้รวบรวมข้อมูลบุคคล ครัวเรือน และชุมชน ทำให้หน่วยงานท้องถิ่นสามารถวางแผน ติดตาม และปรับปรุงบริการสุขภาพได้อย่างมีประสิทธิภาพ ช่วยลดช่องว่างการเข้าถึงบริการสุขภาพ โดยเฉพาะในชุมชนที่อาจถูกละเลย พร้อมทั้งส่งเสริมให้ชุมชนมีบทบาทในการดูแลสุขภาพของตนเองอย่างเป็นระบบและยั่งยืน
</p>
